# Ambag – Smart Expense Splitting Application

**Make Memories, Not Mental Math.**

## About the Project

Ambag is a mobile expense-splitting application developed using Flutter and Dart. It helps users organize shared expenses, calculate individual contributions, and manage group payments conveniently.

The application aims to simplify expense management and promote transparency among friends and groups sharing expenses.

## Features

- **User Authentication** – Register and log in using Firebase Authentication.
- **Create Expense Splits** – Create and manage shared expenses.
- **Equal Splitting** – Divide expenses equally among participants.
- **Item-Based Splitting** – Assign specific expenses to individual participants.
- **Expense Management** – Organize and review shared expenses.
- **Payment Tracking** – Monitor payment information and contributions.
- **User Profile** – Manage user account information.

## Installation and Setup

1. Clone this repository:

   `git clone https://github.com/ChelsieGonzales/Ambag.git`

2. Open the project folder:

   `cd Ambag`

3. Install dependencies:

   `flutter pub get`

4. Configure Firebase for your environment if necessary.

5. Run the application:

   `flutter run`
